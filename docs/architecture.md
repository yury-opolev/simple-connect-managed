# Architecture

## Overview

```
Browser (Blazor WASM)  --->  Azure Functions (.NET 8)  --->  Azure Communication Services
                                     |
                                     +--->  Azure Table Storage (token tracking)
                                     +--->  Azure Key Vault (JWT secret)
```

- **Frontend**: Blazor WebAssembly SPA with Bootstrap 5.3 (all assets served locally, no CDN)
- **Backend**: .NET 8 Azure Functions (isolated worker) with ACS SDK
- **Auth**: Entra ID (MSAL) for admin; single-use JWT invite tokens for guests
- **Infrastructure**: ARM templates deploying to Azure

## Security Model

### Admin authentication
- Entra ID with MSAL (Microsoft Authentication Library)
- Only registered Microsoft accounts can create rooms and manage invites
- Object ID allowlist for additional access control

### Guest authentication
- JWT invite tokens signed with HMAC-SHA256 (secret stored in Key Vault)
- **Time-limited**: configurable expiry (default 24 hours)
- **Single-use**: enforced via Azure Table Storage atomic insert (prevents replay)
- **Room-scoped**: each token is bound to a specific room ID

### Other
- Room IDs generated by ACS -- non-guessable
- HTTPS required for camera/mic access on all browsers
- All static assets (Bootstrap, Bootstrap Icons) served locally -- no CDN dependencies
